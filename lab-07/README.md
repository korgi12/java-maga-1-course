# Лабораторная работа №7

XML-приложение: класс `ru.maga.xml.StudentAverageMain`.

Аргументы запуска в IntelliJ IDEA:

```text
student.xml result.xml
```

Запуск из папки `lab-07` после компиляции:

```bash
java -cp target/classes ru.maga.xml.StudentAverageMain student.xml result.xml
```

Для HTML-калькулятора откройте `web/index.html` в браузере.
